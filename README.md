Safe Till Home
A quiet digital companion for the journey home.
You travel alone. You don't have to feel alone.

Safe Till Home is an interactive concept prototype that reimagines an everyday journey home as a calmer, more connected experience. A user starts a journey, selects a destination and trusted contact, checks in during the journey, and marks arrival.
Demo features
- Start a simulated journey and choose a destination.
- Select a trusted contact.
- View an illustrative route and estimated arrival time.
- Confirm status with I'm Okay.
- Explore the I Need Help interaction.
- Simulate a route change or missed check-in.
- Complete the journey and show the arrival state.
Run locally
1. Download or clone this repository.
2. Open index.html in a modern browser such as Chrome or Edge.
3. Choose a destination and trusted contact.
4. Click I'm Going Home and try the available interactions.
No build step or package installation is required.
Important limitations
This is a front-end concept demonstration using simulated journey data. It does not access GPS, track a real journey, send real notifications, contact trusted contacts, call emergency services, or guarantee personal safety. Route changes and notifications are simulated for demonstration purposes only.
A production version would require explicit consent, secure location handling, tested notification delivery, privacy controls, false-alarm safeguards, and appropriate emergency workflows.
Competition context
Created as a concept for the DJXHack Residency — Everyday Magic challenge. The project focuses on turning the ordinary act of travelling home into a small moment of reassurance.
