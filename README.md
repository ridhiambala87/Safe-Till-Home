# Safe Till Home 🏡

### A quiet digital companion for the journey home.

**You travel alone. You don't have to feel alone.**

🔗 **Live Demo:** https://safe-till-home-demo.vercel.app/

## About the Project

Safe Till Home is an interactive concept prototype that reimagines the everyday journey home as a calmer, more connected experience. It is designed for college students and young women who want to keep a trusted person informed while travelling home.

The concept allows a user to start a journey, choose a destination and trusted contact, respond to safety check-ins, and mark their arrival. If a journey changes unexpectedly or a check-in is missed, the prototype demonstrates a gradual support process.

The goal is to transform an ordinary journey into a small moment of reassurance.

## Features

- **Start a Journey:** Choose a destination and trusted contact.
- **Journey Status:** View simulated route progress and estimated arrival time.
- **One-Tap Check-In:** Confirm that everything is okay.
- **Help Interaction:** Explore the simulated “I Need Help” flow.
- **Route-Change Scenario:** Test how the interface responds to an unexpected route change.
- **Missed Check-In Scenario:** Explore the follow-up interaction.
- **Journey Completion:** Finish the journey and display the arrival confirmation.
- **Responsive Interface:** Designed for a clean experience on desktop and mobile screens.

## How to Try the Demo

1. Open the [Safe Till Home Live Demo](https://safe-till-home-demo.vercel.app/).
2. Select a destination and trusted contact.
3. Click **“I'm Going Home.”**
4. Try the **“I'm Okay”** and **“I Need Help”** interactions.
5. Test **“Simulate Route Change”** and **“Simulate Missed Check-In.”**
6. Click **“Arrived Home”** to complete the journey.
7. Use **“Reset Demo”** to explore the experience again.

## Everyday Magic

Safe Till Home focuses on reassurance rather than fear. Instead of being only an emergency button, it explores how a simple action—starting a journey—can help travellers stay connected with people they trust.

**Journey started → Gentle check-in → Support when needed → Home safely**

## Privacy and Safety Disclaimer

This project is a concept prototype using simulated journey data. It does not access GPS, track real journeys, send actual notifications, contact trusted people, call emergency services, or guarantee personal safety.

A production version would require explicit consent, secure location handling, reliable notification delivery, privacy controls, false-alarm safeguards, and carefully tested emergency workflows.

## Future Scope
